Meine M3U mit fertiger EPG-Zuordnung

Lade deine Original-M3U hoch. Die App übernimmt passende XMLTV-IDs aus unserer EPG, ohne Sender, Streaming-Adressen oder Zugangsdaten zu verändern.

Privat auf deinem Gerät: Deine M3U wird nur im Browser gelesen und als neue Datei heruntergeladen. Sie wird nicht an GitHub oder einen anderen Server geschickt. Die Webseite selbst bleibt öffentlich.

1. Anbieter-Playlist auswählen

Du kannst deine Original-M3U beim IPTV-Anbieter herunterladen und hier auswählen. Die Datei kann vertrauliche Stream-Links enthalten.

2. Meine EPG-Adresse

Dein aktiver Link „Mein EPG“ wird automatisch eingesetzt. Du kannst ihn bei Bedarf ändern.

3. EPG-IDs eintragen und M3U herunterladen

EPG-Senderdaten werden geladen …
–
Playlist-Sender
–
Sicher zugeordnete Sender
–
Ohne neue Zuordnung

Nur eindeutige Treffer werden übernommen. Zweifelhafte, nicht vorhandene und fehlende EPG-IDs bleiben unverändert. Die M3U erhält im Kopf die persönliche XMLTV-URL für unterstützte Player.

Diese Funktion erzeugt eine herunterladbare Datei, keinen dauerhaften öffentlichen M3U-Link. Das schützt die Stream-Adressen vor einer Veröffentlichung auf GitHub Pages. Manche iMPlayer-Versionen benötigen zusätzlich eine manuell eingetragene XMLTV-URL.
